# DeltaForceQJT（三角篓子助手）

《三角洲行动》（Delta Force）单机 / 合作场景下的游戏体验优化辅助工具。通过对屏幕与音频的感知、键鼠输入的模拟，把游戏中高频、重复的机械操作自动化，降低操作负担，提升体验。

> 合规提示：本工具仅对个人公开游戏操作做自动化辅助，不修改、不注入游戏进程内存。是否允许此类工具以游戏运营方的规定为准，请使用者自行评估并遵守《用户协议》。

## 主要功能介绍
<img width="1002" height="852" alt="image" src="https://github.com/user-attachments/assets/dd875d2c-f963-465d-9d49-b45597fbae9e" />

- **功能开关**：统一的总闸页，按需开启 / 关闭下列各项辅助功能，所见即所得。
- **取消刀法**：针对特定场景的自动化取消 / 收刀操作辅助。
- **威慑爆闪**：提供威慑与爆闪相关的快捷操作辅助。
- **自动解锁电脑（含每日密码门）**：游戏内骇客电脑小游戏中，按助手热键自动输入当日密钥。
  - 摩斯码：`Ctrl + Alt + Q`
  - 指纹：`Ctrl + Alt + W`
  - 密码门：`Ctrl + Alt + E`（在密码门输入界面按此热键即可自动输入当日密钥）
  - 每日密码门数据来源于**游戏公开数据接口**，仅在首次开启时获取并缓存到本地，当日 00:00 自动静默刷新，避免高频请求。
- **自动演奏**：自动完成游戏内演奏 / 演奏类小游戏的操作。
- **自动钓鱼**：通过音频环回采集实时判断咬钩与拉起时机，自动完成钓鱼流程；内置多种背景音乐模板。
- **卡密管理 / 授权**：
  - 采用**一机一码**授权体系，授权状态与可用功能位由服务端统一下发，按机绑定、可控可管。
  - 客户端内置**完整性自校验（防篡改）**，任何对程序文件的篡改都会在启动时自检失败并终止运行。
  - 提供激活绑定与"立即心跳"刷新授权；授权过期 / 功能位变化由服务端实时控制。
- **改键示例**：提供游戏内按键绑定参考图，便于对照设置。
- **运行状态 / 版本信息**：实时展示功能开启数量、授权状态与到期时间，便于掌握当前状态。

## 使用方法

1. 从 Releases 下载 `DeltaForceQJT-v1.1.0.zip`，**解压到任意目录**。**迁移到新电脑时请整包复制解压后的目录**，不要拆分其中的文件（`PicRes\` 必须与主程序同级，否则界面空白）。
2. 需要使用「自动解锁电脑」时，请另外下载 Releases 中的 `DeltaForceCodeAssistant.exe`，**放到与主程序相同的目录下**；不需要该功能则可不下载。
3. 以**管理员身份**运行 `DeltaForceQJT.exe`。
4. 在「功能开关」页开启所需功能。
5. 首次使用请在「卡密管理」页完成授权激活，并保持网络畅通以完成授权心跳。

6. 进入对应游戏场景后，按页面提示使用热键或交由助手自动完成。
